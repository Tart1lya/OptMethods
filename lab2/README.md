Студент: Артемов Илья Витальевич, поток 1.1, вариант 1.

## Задача

Найти приближённо глобальный минимум липшицевой функции одной переменной на отрезке `[a, b]` с точностью `eps`.

Вход программы: строка с функцией (например, `f(x) = x + sin(3.14159*x)`), концы отрезка `a`, `b`, точность `eps`.
Выход: график функции, ломаные (вспомогательные функции) с итоговой ломаной, приближённые `x*` и `f(x*)`, число итераций, время счёта.

## Метод

Метод ломаных (Пиявского): по найденным значениям функции строится ломаная `F_n(x) = max_i (f_i - L|x - x_i|)`, которая нигде не выше `f`. Следующее испытание делается в точке самого низкого излома ломаной. Остановка, когда разность между лучшим найденным значением и наименьшим значением ломаной не больше `eps`: тогда найденное значение отличается от глобального минимума не более чем на `eps`.

Константа Липшица `L` на вход не подаётся: программа оценивает её по сетке из 200001 узла (наибольшее разностное отношение).

## Результат на тестовой функции

Одномерный срез `y = 0` функции Растригина `f(x) = 10 + x^2 - 10cos(2πx)`, отрезок `[-3, 4]`, `eps = 0.01`. На отрезке 8 локальных минимумов (по условию требуется не менее двух).

| L | x* | f(x*) | Итераций | Время, с |
|---|---|---|---|---|
| 69.3327 | -0.000107 | 2.3e-6 | 135 | 0.0089 |

Время зависит от компьютера и запуска.

## Как запустить

Нужен Python 3 с `numpy` и `matplotlib`; команда выполняется из папки `lab2`.

```bash
python3 piyavsky.py
```

Программа спросит функцию, концы отрезка и точность, например:

```
Функция f(x): f(x) = 10 + x^2 - 10*cos(2*pi*x)
Левый конец отрезка a: -3
Правый конец отрезка b: 4
Точность eps: 0.01
```

Затем она выведет результаты и откроет график.

Сборка PDF (любой XeLaTeX-движок, например [tectonic](https://tectonic-typesetting.github.io/)):

```bash
tectonic -X compile report.tex
```
