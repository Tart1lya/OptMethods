# Лабораторная работа "Методы оптимизации": условные экстремумы методом множителей Лагранжа

Студент: Артемов Илья Витальевич, поток 1.1, вариант 2.

## Задача

Найти минимум и максимум функции `f(x, y) = x*y` при ограничении `h(x, y) = x² + y² - 8 = 0`. Переменные `x` и `y` действительные. Условие взято из раздела "Свой вариант" файла `lagrange-lecture.html`.

Исходные данные программы: целевая функция и ограничение, заданные в коде для варианта 2.
Выход: функция Лагранжа, полная система уравнений, все действительные корни, невязка ограничения и значение `f` в каждой точке.

## Метод

Метод множителей Лагранжа: строится функция `L = f + lambda*h`, её производные по `x`, `y` и `lambda` приравниваются к нулю. Полученная система решается полностью, найденные точки подставляются в ограничение и целевую функцию.

Программа сама вычисляет производные через `sympy.diff` и решает систему через `sympy.solve`. Глобальность обоснована в ручном решении: на окружности минимум и максимум существуют, все её точки регулярны, поэтому достаточно сравнить значения во всех стационарных точках. Ручной и программный ответы приведены рядом в таблице отчёта.

## Результат для варианта 2

Функция `f(x, y) = x*y`, окружность `x² + y² = 8`. Найдены четыре действительных решения системы.

| Точки               | lambda | h | f  | Результат                    |
| ------------------------ | ------ | - | -- | ------------------------------------- |
| `(2, 2)`, `(-2, -2)` | -1/2   | 0 | 4  | глобальный максимум |
| `(2, -2)`, `(-2, 2)` | 1/2    | 0 | -4 | глобальный минимум   |

Результаты ручного расчёта и программы совпали.
