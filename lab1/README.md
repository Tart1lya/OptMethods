## Задача

Максимизировать `Z = 2x1 + 3x2 + x3 + 4x4` при условиях

```
 x1 +  x2 +  x3 + x4 <= 10
2x1 +  x2 -  x3 + x4  =  8
       x2 + 2x3 + x4 >=  5
```

## Метод

Двухфазный симплекс-метод: приведение к каноническому виду, вспомогательная задача с искусственными переменными, переход к основной задаче, решение основной задачи, ответ.

Проверка (шаг 7): вместо Excel использованы Google Таблицы с надстройкой SolveSheet (Solver, метод Simplex LP). Результат совпал: `x* = (0, 0, 1, 9)`, `Z = 37`.

## Ответ

```
x* = (0, 0, 1, 9),   Z(x*) = 37
```

Дополнительные переменные: `x5 = 0`, `x6 = 6`.

## Как запустить

Решение и проверка (нужен Python 3; `scipy` необязателен, без него пропускается только сверка):

```bash
python3 simplex.py
```

Те же таблицы в виде кода LaTeX:

```bash
python3 simplex.py --latex
```

Сборка PDF (любой XeLaTeX-движок, например [tectonic](https://tectonic-typesetting.github.io/)):

```bash
tectonic -X compile report.tex
```
